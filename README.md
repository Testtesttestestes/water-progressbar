# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/b5900ef9-5bf6-4f38-b1c9-60272d50b2e5

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Как устроена вода

Вода считается сеточным решателем несжимаемых уравнений Навье–Стокса на GPU (`src/fluid/`), а не частицами:

- **Двухфазный расчёт: вода и воздух.** Сетка MAC связана с колбой: стенки в ней неподвижны, а движение колбы входит в уравнения силами инерции (переносной, Эйлера, центробежной, Кориолиса). Скруглённые стенки заданы долями открытости граней (cut-cell), поэтому у углов нет «лесенки».
- **Перенос.** Скорость и граница воды переносятся схемой MacCormack с ограничителем.
- **Давление.** Метод проекции Чорина, давление считается многосеточным V-циклом (красно-чёрный Гаусс–Зейдель). Тяжесть и центробежная сила входят через скачок давления на границе вода/воздух («призрачная жидкость»), поэтому ровная поверхность в покое неподвижна при любом наклоне.
- **Объём воды точно равен прогрессу.** Level set поправляется по объёму на каждом шаге: 100% — колба полная, 0% — пустая.
- **Пузырьки** (`bubbles.ts`) — частицы на GPU. Их несёт поле скорости, они всплывают и лопаются у поверхности. Часть прилипла к стеклу, часть — пена у мениска.
- **Отрисовка** (`renderer.ts`, `renderShaders.ts`):
  - толстое стекло: преломление и светлая кайма на скосе рёбер, блики;
  - прозрачная вода с полосой поверхности, видимой почти с ребра;
  - мениск у стекла и каустики.

Масштаб: колба шириной 10 единиц соответствует примерно 60 см, ползунок Gravity = 1 — земная тяжесть.
