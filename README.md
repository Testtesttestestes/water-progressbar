# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/b5900ef9-5bf6-4f38-b1c9-60272d50b2e5

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Как устроена вода

Вода считается сеточным решателем несжимаемых уравнений Навье–Стокса на GPU (`src/fluid/`), а не частицами:

- **Двухфазный расчёт: вода и воздух.** Сетка MAC связана с колбой: стенки в ней неподвижны, а движение колбы входит в уравнения силами инерции (переносной, Эйлера, центробежной, Кориолиса). Скруглённые стенки заданы долями открытости граней (cut-cell), поэтому у углов нет «лесенки».
- **Перенос.** Скорость и граница воды переносятся схемой MacCormack с ограничителем.
- **Давление.** Метод проекции Чорина, давление считается многосеточным V-циклом (красно-чёрный Гаусс–Зейдель). Тяжесть и центробежная сила входят через скачок давления на границе вода/воздух («призрачная жидкость»), поэтому ровная поверхность в покое неподвижна при любом наклоне.
- **Объём воды точно равен прогрессу.** Level set поправляется по объёму на каждом шаге: 100% — колба полная, 0% — пустая.
- **Пузырьки** (`bubbles.ts`) — частицы на GPU. Их несёт поле скорости, они всплывают и лопаются у поверхности. Часть прилипла к стеклу, часть — пена у мениска.
- **Брызги и капли** (`spray.ts`) — частицы на GPU:
  - брызги рождаются там, где поверхность быстро уходит в воздух, и летят под тяжестью колбы; упавшие в воду сливаются с ней, долетевшие до стекла остаются каплями;
  - капли остаются и там, откуда вода только что отступила: плёнка на стекле рвётся на капли;
  - мелкие капли держатся на стекле, крупные сползают, все понемногу испаряются.
- **Каустики** (`caustics.ts`) — свет, преломлённый рябью поверхности (закон Снеллиуса, яркость — отношение площадей пучка):
  - стенка колбы пропускает свет по формулам Френеля, поэтому при наклоне свет распределяется неравномерно;
  - второй путь света — сквозь стенку ниже уровня воды: там ряби нет;
  - источник протяжённый, поэтому у теней есть полутень.
- **Отрисовка** (`renderer.ts`, `renderShaders.ts`):
  - толстое стекло: преломление и светлая кайма на скосе рёбер, блики;
  - прозрачная вода с полосой поверхности, видимой почти с ребра;
  - мениск у стекла;
  - капли как линзы: внутри перевёрнутое изображение того, что за ними, тёмная кайма, блик источника и светлое пятно фокуса.

## Встраивание (прозрачный режим)

```tsx
<div style={{ position: 'relative', width: 640, height: 200 }}>
  <RealisticProgressBar progress={0.53} background={null} fullscreen={false} />
</div>
```

- `background={null}` — холст прозрачный: колба и вода рисуются сами по себе, поверх любого интерфейса. Сцена считается дважды, на чёрном и на белом фоне, и по разнице восстанавливается цвет и непрозрачность каждого пикселя. Сквозь воду видно саму страницу (без искажения: WebGL не видит DOM за холстом), отражения берутся из нейтральной «студии».
- `background="https://…"` — картинка, которая преломляется в воде (как в демо). Можно передать и готовую картинку или холст (`HTMLImageElement`, `HTMLCanvasElement`, `ImageBitmap`). Если картинка не загрузилась (часто — сервер не разрешает CORS), в консоли будет предупреждение, а вместо неё — ровный градиент, в котором искажений не видно.
- `backgroundFit="page"` — фон натягивается на окно браузера и выравнивается с положением холста. Передайте ту же картинку, что лежит фоном страницы, и стекло будет искажать именно то, что за ним; вне колбы холст прозрачный:

  ```tsx
  <RealisticProgressBar progress={p} fullscreen={false}
    background="/wallpaper.jpg" backgroundFit="page"
    backgroundTint={[1, 1, 1, 0.25]} />   {/* полупрозрачная панель под колбой */}
  ```

  Страница должна рисовать эти обои тоже «cover» на всё окно (`background: url(...) center/cover fixed`). Кнопки и текст под колбой в искажение не попадают — только фон.
- `backdrop={element}` — искажается живая страница: кнопки, текст, картинки на кнопках. Колба снимает элемент (SVG foreignObject → холст) и преломляет снимок; снимок обновляется при изменении DOM, наведении, нажатии, прокрутке и раз в секунду, но не чаще `backdropInterval` мс (по умолчанию 250). Вода и преломление анимируются каждый кадр, меняется только картинка под ними.

  ```tsx
  <div style={{ position: 'absolute', inset: 0, pointerEvents: 'none' }}>
    <RealisticProgressBar progress={p} fullscreen={false} backdrop={appRootElement} />
  </div>
  ```

  - Передавайте непрозрачный контейнер (корень окна приложения с его обоями): у полупрозрачного элемента в снимок не попадёт то, что под ним.
  - Обёртке колбы нужен `pointer-events: none`, иначе она перекроет клики по кнопкам под ней.
  - Картинки (`<img>` и обои самого контейнера) должны быть с того же адреса, что и страница (или `data:`): чужие браузер не даст прочитать. Картинки рисуются прямо из уже загруженных, с `object-fit` и скруглением углов; фоновые картинки у вложенных элементов в снимок не попадают.
- `fullscreen={false}` — холст заполняет родителя, камера держит колбу в кадре при любом наклоне и качании.

Масштаб: колба шириной 10 единиц соответствует примерно 60 см, ползунок Gravity = 1 — земная тяжесть.
